# NeonKey — каталог цифровых товаров (v2.0)

Telegram Mini App + обычный сайт для продажи цифровых товаров (Steam,
Telegram Stars и т.д.). С версии 2.0 сайт работает как **каталог-витрина**:
сам приём оплаты и выдачу товара выполняет партнёрская площадка
**Digiseller / plati.market** — на стороне сайта не остаётся ни баланса,
ни собственных таблиц заказов.

## Что изменилось в 2.0

- ❌ Убрано пополнение баланса и вся логика "своих" денег на сайте.
- ❌ Убрана админ-панель (курсы, минималки, ручное подтверждение заказов) —
  она была нужна только для старой модели с собственным балансом.
- ✅ Каталог — теперь это просто список товаров в `webapp/js/data/catalog.js`,
  редактируется прямо в коде.
- ✅ Покупка = переход на страницу оплаты конкретного товара на Digiseller,
  открывается во встроенном окне поверх сайта (без ухода на отдельную
  вкладку — если конкретная страница оплаты не запрещает показ во фрейме,
  иначе рядом есть кнопка "Открыть в новой вкладке").
- ✅ Авторизация — email + пароль + код подтверждения на почту
  (Supabase Auth), работает одинаково что на сайте, что в Telegram Mini App.
- ✅ Раздел "Информация" переписан под новую модель (кто принимает оплату,
  как работает доставка, где искать историю покупок, промокоды).
- ⚡ Общая оптимизация: удалены неиспользуемые модули (админка, депозиты,
  история заказов, отдельные Supabase-таблицы users/orders/settings и весь
  код, который их дергал), убран тяжёлый `backdrop-filter` на мобильных
  устройствах (основная причина "тормозов" в интерфейсе на телефонах).

## Что нужно донастроить перед запуском

### 1. Supabase — код подтверждения вместо ссылки в письме
По умолчанию Supabase Auth шлёт письмо со ссылкой ("Confirm your signup"),
а не 6-значным кодом. Чтобы пользователь получал именно код:

1. Зайди в свой проект Supabase → **Authentication → Email Templates**.
2. Открой шаблон **Confirm signup**.
3. В тексте письма замени `{{ .ConfirmationURL }}` на `{{ .Token }}` —
   это переменная с 6-значным кодом.
4. Сохрани. Всё остальное (проверка кода) уже реализовано в
   `webapp/js/lib/auth.js` → `verifyEmailOtp()`.

Без этого шага регистрация формально будет работать, но письмо будет
по-прежнему со ссылкой, а не с кодом.

### 2. Digiseller — ссылки на оплату товаров
1. Заведи аккаунт продавца на Digiseller (plati.market), добавь свои товары
   с ценой, уже включающей твою наценку.
2. Для каждого товара получи ссылку на страницу оплаты (в личном кабинете
   Digiseller: Товары → нужный товар → «Продавать на своём сайте» /
   «Получить HTML-код ссылки на оплату»).
3. Вставь эти ссылки в `webapp/js/data/catalog.js`, поле `digisellerUrl`,
   для каждого товара.
4. Промокоды/скидки настраиваются в самом Digiseller у товара и вводятся
   покупателем прямо на странице оплаты — на сайте их обрабатывать не нужно.

**Важно:** Digiseller (как и любой платёжный сайт) может запрещать показ
своей страницы во фрейме — тогда покупатель просто нажмёт «Открыть в новой
вкладке» в окне оплаты. Это нормально, проверяется только на реальных
товарах после того, как ссылки будут добавлены.

### 3. Bot
Токен бота в `bot/config.py` — тестовый и уже "засвечен" в переписке,
перед публичным запуском обязательно отзови его через @BotFather → `/revoke`
и впиши новый в `.env` (см. `bot/.env.example`).

## Структура проекта

```
webapp/
  index.html
  css/            base, overlays (авторизация), profile, shop, info, nav, modals
  js/
    config.js     ключи Supabase, ссылки
    state.js      состояние приложения (текущий пользователь, аватар)
    data/
      catalog.js  список товаров + ссылки на оплату Digiseller
    lib/
      auth.js           Supabase Auth (email/пароль/код)
      supabaseClient.js
      telegram.js       опциональная интеграция с Telegram Mini App
    ui/
      authScreen.js     вход/регистрация/код подтверждения
      catalogView.js    рендер каталога
      digisellerModal.js окно оплаты
      profileView.js
      avatarModal.js
      docsModal.js       Политика/Оферта
      tabs.js
      toast.js
      loadingOverlay.js
      welcomeModal.js
    content/
      legalDocs.js  тексты Политики и Оферты (шаблон, показать юристу)
    main.js         точка входа
bot/
  main.py, config.py, keyboards.py, handlers/start.py
```

## Локальный запуск
`webapp/` — статические файлы, достаточно любого HTTP-сервера
(например, `npx serve webapp` или деплой на Vercel/Netlify).

`bot/` — Python 3.11+, `pip install -r requirements.txt`, затем
`python main.py`.
